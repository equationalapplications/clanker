Frequently Asked Questions

How does Power work?

Power is what you use in Clanker AI. Chat replies, image generation, live voice, cloud character saves/sync, document ingestion, and memory writes all use Power. The Power meter at the top of the app shows how much you have left. The monthly plan refills your Power every billing cycle; one-time packs add Power that lasts 31 days.

How do I get more Power?

Monthly plan ($20/month): 30,000 Power, refills automatically every billing cycle. One-time pack ($10): 10,000 Power, valid for 31 days. Purchase from the Subscribe screen in the app.

Does Power expire?

Free signup Power (5,000) never expires. Monthly plan Power expires at the end of each billing cycle, when it refills. One-time pack Power expires 31 days after purchase.

How much Power does each action use?

A text chat reply in the Chat tab uses 100–300 Power. Live real-time voice in the Talk tab uses 500 Power to connect plus 500 Power per minute. Generating an image uses 200 Power — see how in-chat images work. Converting a document uses 200 Power, and each agent turn uses 100 Power per loop. See how live voice works in action.

How do I sign in?

Open Clanker AI and choose Google or Apple sign-in. Use the same provider each time so your account data loads correctly.

How do I delete my account?

Delete your account from the Profile page using the Delete Account button.

Can I export my character's memory?

Yes — open Character Settings and tap Export Memory as OKF for a complete backup. Restore with Import OKF Backup or clone with From Bundle on the characters list. See our OKF memory export guide.
